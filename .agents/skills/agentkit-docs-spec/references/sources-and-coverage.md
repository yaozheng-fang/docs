# 来源与覆盖清单

整理日期：2026-09-19

本技能覆盖下列来源中与文档质量有关的规则，进行了去重、中文整理和 AgentKit 适配。覆盖以本页列出的来源与主题为边界；Google 写作指南包含更多专题，遇到未覆盖的具体用法时应查阅对应官方页面

本技能不涵盖构建器专属语法与配置。Google 专用目录元数据、目录自动发现、固定模型和变量名称、自动生成流程、维护人员分工及特定 PR 模板也不作为通用写作规范。相关内容如果承载了可复用的质量原则，已经在下表映射到适配规则

## 适配原则与维护

- 写作目的、事实依据、完整性和读者可操作性优先于表面格式的一致
- 通用建议保留条件：可选项、语言差异、命令参考、装饰图、签名片段、Preview 和粗看范围都有明确例外
- 来源中的收录与 PR 管理规则只在相应审查任务启用，不扩大普通写作权限
- 当前仓库与 Google 建议不一致时，以根规范和用户要求为准；如果要修改根规范，应作为用户明确要求的独立事项
- 更新技能时对照固定来源的变化，逐项确认新增规则进入对应参考；删除或不采用规则应在此记录理由，避免无意遗漏
