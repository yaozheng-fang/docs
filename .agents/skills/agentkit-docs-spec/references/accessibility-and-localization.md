# 无障碍与双语

来源：Google 写作指南的 Write accessible documentation、Write for a global audience、Highlights 与链接建议。标识 A 用于来源覆盖清单

## A1 可理解的阅读顺序

- 使用语义化标题、列表、表头和站点原生组件，不靠字号、颜色、位置或自定义样式表达结构
- 标题不跳级，不用空标题；正文左对齐，避免长篇居中或两端强制对齐
- 不为视觉效果在句中插入强制换行，保证缩放和窄屏下仍然连贯。Markdown 源文件折行与页面中的硬换行不是一回事
- 缩写在首次需要时解释，同一术语保持大小写一致；公开 API 的 camelCase 和全大写常量不应为朗读而改名
- 重要信息放在段落开头，句子和列表结构平行，避免双重否定与过多标点。Google 的英文约 26 词建议用于发现长句，不作为中文或所有句子的硬性限额
- 重要含义不只依靠标点、颜色、图标或视觉位置传达；状态同时提供文字标签
- 引用控件名称或可访问名称，不写“右上角按钮”“三个横线”；需要定位时配截图，并保留文字操作说明
- 不用对某些群体有偏见、侮辱性或能力假设的表达；产品有专门无障碍能力时，应说明实际用法

## A2 链接

- 链接文字在脱离上下文时仍说明目的地，例如“配置模型凭证”，不用“这里”“点击查看”“read this document”
- 尽量避免紧挨着的多个链接，使用标点或有意义的连接文字分隔
- 链接下载文件、打开新标签页或跳到同页特定区域等行为可能出乎预期时，提前说明
- 交叉引用使用清楚的说明性引导；英文通常用 see。不要只用“上面”“下面”或方向作为引用依据
- 使用直接、稳定的目的地，内部链接与站点路径规则一致；可访问性检查不能代替链接存在性核验

## A3 图片、视频与图表

- 每张图片提供与用途相符的 alt 属性。纯装饰图可用空 alt；有信息的图必须有描述，不能把所有空 alt 都机械判错
- 图中的新信息应有等价文字说明，代码和终端输出使用文本，不用截图替代可复制内容
- 同一图片不要无必要地重复；优先清晰的高分辨率图片或 SVG，允许放大阅读
- 图标和流程图中的状态或差异不能只靠颜色、形状或线条粗细区分，要有文字标识
- 视频和音频提供字幕、文字稿或描述；字幕应可翻译，不使用闪烁或快速闪光效果
- 截图内文字不易翻译，双语内容尽量把操作信息放在正文，必要时提供对应语言截图

## A4 表格与交互

- 表格前说明用途，表头清晰；简单 Markdown 表格通常优先于复杂 HTML 表格
- 自定义 HTML 表格正确关联表头与单元格：需要时使用 `th`、`scope`、`headers` 和唯一 ID；尽量避免合并单元格和多层表头
- 表格不是列表和正文的默认替代，不把长表格插在一组操作步骤中打断流程
- 标签页、展开区、按钮和表单应可用键盘到达和操作。内容需要展开时，用正文说明该区域包含什么
- 使用原生按钮和带可见标签的表单字段；标签放在输入框之外，错误说明哪里有问题以及如何修复
- 菜单路径优先用文字“然后”，或使用站点支持的可访问表达；自定义 `>` 导航必要时提供能读为“然后”的标签
- 优先沿用站点组件；确需自定义时，文字对比度一般至少 4.5:1，DOM 阅读顺序与视觉顺序一致，鼠标悬停内容也可通过焦点访问
- 不把必需内容以 `display:none`、`visibility:hidden` 永久隐藏而不给可访问路径；可折叠组件可以按正确语义管理隐藏状态，不因此一律禁用隐藏样式
- 深度无障碍审查可按任务需要检查键盘、屏幕阅读器、放大、无图、无色、静音及纯音频场景；普通文字修改不要求每次执行全部场景

## A5 全球读者与双语

- 翻译转换语言，本地化还包括地区、币种和单位等适配；不能只翻正文而忽略示例、UI 名称和区域差异
- 用常见词和简短句子，少用难以直译的短语动词、习语、俚语、笑话、节日、体育和季节隐喻；set up、log in 等惯用表达可保留
- 避免把同一个词在相邻句中用于不同含义；同一概念使用相同名称、大小写和格式
- 修饰语贴近修饰对象，英文通常不连续堆超过两个名词修饰另一个名词；含义优先于机械计数
- 英文用主动语态、现在时和常见语序，必要时补充 that、which、then、of 等词；明确指代，避免省略导致歧义
- 技术名词有适当的限定词，例如 the `example.yaml` file；适量重复能改善理解时不为追求简短而删除
- 英文按规范使用复数、所有格和缩写，不用 's 构造复数，不随意把商标变成复数或所有格，不用罕见缩约形式
- 面向操作者直接说明任务，避免不必要的否定句；日期、时间、单位和地区说明无歧义
- 如需人名和示例地址，使用虚构且多样的示例，不假设所有用户来自同一地区
- 中英文共用同一组事实：参数、默认值、版本、限制、警告、示例、链接和导航等价；不要只比文件数量或段落数
- 英文表格、错误说明和示例中的中文需要逐项判断：一般提供英文等价内容；专门演示中文处理能力的原始样本可以保留，但应说明用途
