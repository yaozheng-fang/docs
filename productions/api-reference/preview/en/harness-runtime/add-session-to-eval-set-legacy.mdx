This underscore path uses the same request and response as its hyphenated counterpart and remains available to existing clients. Confirm that the session and set exist, and review the conversation data that will be saved as a sample

<Warning>
Writing or deleting evaluation samples changes the actual evaluation set
</Warning>

See the [corresponding evaluation endpoint](/productions/api-reference/preview/en/harness-runtime/add-session-to-eval-set) for the replacement and its complete requirements
