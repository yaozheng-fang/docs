This underscore path uses the same request and response as its hyphenated counterpart. It deletes the specified case, which is then excluded from future evaluations; preserve any content you need first

<Warning>
Writing or deleting evaluation samples changes the actual evaluation set
</Warning>

See the [corresponding evaluation endpoint](/productions/api-reference/preview/en/harness-runtime/delete-eval-case) for the replacement and its complete requirements
