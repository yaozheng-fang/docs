This deprecated endpoint remains available for existing clients. New integrations should use [Create a session](/productions/api-reference/preview/en/harness-runtime/create-session) and set `sessionId` in the request body

The body of this endpoint is the initial state itself, such as `{"language":"zh"}`. When migrating, change it to `{"sessionId":"session-001","state":{"language":"zh"}}` and remove the session ID from the path
