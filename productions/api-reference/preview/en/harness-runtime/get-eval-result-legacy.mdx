This deprecated endpoint remains available for existing clients to read saved evaluation results. In this baseline, its response fields match the replacement, including `evalSetResultId` and `evalCaseResults`; do not convert them to snake_case

See the [corresponding evaluation endpoint](/productions/api-reference/preview/en/harness-runtime/get-eval-result) for the replacement and its complete requirements
