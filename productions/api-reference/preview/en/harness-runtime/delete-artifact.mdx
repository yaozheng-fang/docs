---
title: "Delete an artifact"
openapi: "/productions/api-reference/openapi/en/harness-runtime.json DELETE /apps/{app_name}/users/{user_id}/sessions/{session_id}/artifacts/{artifact_name}"
zh_link: "/productions/api-reference/preview/zh/harness-runtime/delete-artifact"
---

<Warning>
This operation deletes the named artifact and all its versions, including older versions. The endpoint provides no restore operation; preserve any content you need before deleting it
</Warning>

Success returns HTTP `200` with JSON `null`. Check the artifact version list and metadata first if you need to confirm the target
