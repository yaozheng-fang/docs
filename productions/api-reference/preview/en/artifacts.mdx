Artifacts are text, images, and other file content generated by agents or saved by applications. A name can have multiple versions. This page indexes Agent API Server endpoints; Harness deployments have separate [artifact endpoints](/productions/api-reference/preview/en/harness-runtime/list-artifacts)

A save response returns the version number, a content read returns a `Part`, and metadata endpoints return URI, MIME type, and custom information. Deleting an artifact removes all its versions; preserve any content you need first

| --- | --- | --- |

| GET | `/apps/{app_name}/users/{user_id}/sessions/{session_id}/artifacts` | [List artifacts](/productions/api-reference/preview/en/agent-api-server/list-artifacts) |
