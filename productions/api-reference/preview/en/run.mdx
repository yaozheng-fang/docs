Create a session under the target application and user before submitting a message. `/run` returns an event array after completion; `/run_sse` streams events, requiring the client to handle in-stream errors and read until closure

Calls save session events, and model or tool execution can incur charges or perform external actions. Harness overrides and streaming behavior differ; see [Harness Runtime API](/productions/api-reference/preview/en/harness-runtime/overview)

| Method | Path | Endpoint |
| --- | --- | --- |
| POST | `/run_sse` | [Run an agent with SSE](/productions/api-reference/preview/en/agent-api-server/run-sse) |
| POST | `/run` | [Run an agent](/productions/api-reference/preview/en/agent-api-server/run) |
