---
title: "Evaluation"
---

Manage evaluation sets and cases, run evaluations, and read results

<Note>
These endpoints use `/dev/...` paths and require the development server. A regular `adk api_server` does not expose them. See [Agent API Server overview](/productions/api-reference/preview/en/agent-api-server/overview) for startup options
</Note>

| --- | --- | --- |

| GET | `/dev/apps/{app_name}/eval-sets` | [List evaluation sets](/productions/api-reference/preview/en/agent-api-server/list-eval-sets) |
