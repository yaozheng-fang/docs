---
title: "Debugging"
---

Inspect event traces, session traces, and agent graphs

<Note>
These endpoints use `/dev/...` paths and require the development server. A regular `adk api_server` does not expose them. See [Agent API Server overview](/productions/api-reference/preview/en/agent-api-server/overview) for startup options
</Note>

| Method | Path | Endpoint |
| --- | --- | --- |
| GET | `/dev/apps/{app_name}/debug/trace/{event_id}` | [Get an event trace](/productions/api-reference/preview/en/agent-api-server/get-event-trace) |
| GET | `/dev/apps/{app_name}/users/{user_id}/sessions/{session_id}/events/{event_id}/graph` | [Get an event graph](/productions/api-reference/preview/en/agent-api-server/get-event-graph) |
| GET | `/dev/apps/{app_name}/debug/trace/session/{session_id}` | [Get session traces](/productions/api-reference/preview/en/agent-api-server/get-session-trace) |
| GET | `/dev/apps/{app_name}/graph` | [Get the agent graph](/productions/api-reference/preview/en/agent-api-server/get-agent-graph) |
