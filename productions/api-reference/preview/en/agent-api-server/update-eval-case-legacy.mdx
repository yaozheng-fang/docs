This underscore path uses the same request and response as its hyphenated counterpart. It replaces the complete case; preserve any sample content you need and ensure the request and path case IDs match

<Warning>
Writing or deleting evaluation samples changes the actual evaluation set
</Warning>

See the [corresponding evaluation endpoint](/productions/api-reference/preview/en/agent-api-server/update-eval-case) for the replacement and its complete requirements
