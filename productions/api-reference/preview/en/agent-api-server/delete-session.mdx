title: "Delete a session"
openapi: "/productions/api-reference/openapi/en/agent-api-server.json DELETE /apps/{app_name}/users/{user_id}/sessions/{session_id}"
zh_link: "/productions/api-reference/preview/zh/agent-api-server/delete-session"
---

<Warning>
This operation deletes the session and its history for the specified application and user. This endpoint provides no restore operation. Preserve any state and events you need, and confirm the session identifier first
</Warning>

Success returns HTTP `200` with JSON `null`, rather than `204`. Deleting a session does not undo external actions already completed by tools
