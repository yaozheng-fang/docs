The server must expose development evaluation endpoints. Create an empty set with `evalSet.eval_set_id`; this endpoint does not import `eval_cases` supplied in the request. To add an existing session, use [Add a session as an evaluation case](/productions/api-reference/preview/en/agent-api-server/add-session-to-eval-set)

The returned set has the requested ID. A duplicate ID or invalid input can return `400`. This operation does not run the agent
