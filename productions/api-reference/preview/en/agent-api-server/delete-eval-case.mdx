---
title: "Delete an evaluation case"
openapi: "/productions/api-reference/openapi/en/agent-api-server.json DELETE /dev/apps/{app_name}/eval-sets/{eval_set_id}/eval-cases/{eval_case_id}"
zh_link: "/productions/api-reference/preview/zh/agent-api-server/delete-eval-case"
---

<Warning>
This operation removes one case from the specified evaluation set. Subsequent runs of the whole set exclude it. Preserve any sample you need first; this endpoint provides no restore operation
</Warning>

Success returns JSON `null`. A missing evaluation set or case returns `404`
