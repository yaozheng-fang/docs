制品是智能体生成或应用保存的文本、图片和其他文件内容，同一名称可以有多个版本。本页索引 Agent API Server 的制品接口；Harness 部署请使用其独立的[制品接口](/productions/api-reference/preview/zh/harness-runtime/list-artifacts)

保存响应返回版本号，读取内容返回 `Part` 对象；元数据接口返回 URI、MIME 类型与自定义信息。删除制品会删除全部版本，操作前保存需要保留的内容

| 方法 | 路径 | 接口 |
| --- | --- | --- |
| GET | `/apps/{app_name}/users/{user_id}/sessions/{session_id}/artifacts/{artifact_name}/versions/metadata` | [列出制品版本元数据](/productions/api-reference/preview/zh/agent-api-server/list-artifact-metadata) |
| GET | `/apps/{app_name}/users/{user_id}/sessions/{session_id}/artifacts` | [列出制品](/productions/api-reference/preview/zh/agent-api-server/list-artifacts) |
| GET | `/apps/{app_name}/users/{user_id}/sessions/{session_id}/artifacts/{artifact_name}/versions` | [列出制品版本](/productions/api-reference/preview/zh/agent-api-server/list-artifact-versions) |
| GET | `/apps/{app_name}/users/{user_id}/sessions/{session_id}/artifacts/{artifact_name}/versions/{version_id}/metadata` | [获取制品版本元数据](/productions/api-reference/preview/zh/agent-api-server/get-artifact-metadata) |
| GET | `/apps/{app_name}/users/{user_id}/sessions/{session_id}/artifacts/{artifact_name}/versions/{version_id}` | [读取指定制品版本](/productions/api-reference/preview/zh/agent-api-server/get-artifact-version) |
| POST | `/apps/{app_name}/users/{user_id}/sessions/{session_id}/artifacts` | [保存制品](/productions/api-reference/preview/zh/agent-api-server/save-artifact) |
| DELETE | `/apps/{app_name}/users/{user_id}/sessions/{session_id}/artifacts/{artifact_name}` | [删除制品](/productions/api-reference/preview/zh/agent-api-server/delete-artifact) |
| GET | `/apps/{app_name}/users/{user_id}/sessions/{session_id}/artifacts/{artifact_name}` | [读取最新制品](/productions/api-reference/preview/zh/agent-api-server/get-artifact) |
