默认先[创建会话](/productions/api-reference/preview/zh/agent-api-server/create-session)，再提交消息。`streaming` 默认为 `false`，此时仍通过 SSE 发送完整事件；设为 `true` 时请求模型增量输出

<Warning>
运行会写入会话事件，并可能调用模型、工具与外部资源。重试请求可能再次执行外部操作
</Warning>

每个 SSE 消息以 `data:` 开头，后接 JSON，并以空行结束。使用 `curl -N` 持续读取；事件可能只包含状态或制品变更，不一定包含文本，`partial: true` 表示增量内容

```text
data: {"content":{"role":"model","parts":[{"text":"Hello"}]},"partial":false,"author":"travel_assistant","invocationId":"invocation-001","id":"event-001","timestamp":1789603200}

data: {"error":"Example execution error"}

```

以上分别展示消息事件与错误事件的格式，不表示每次成功调用都会返回错误。HTTP `200` 仅表示流已开始；客户端还需检查流中的 `error`，并读取到连接结束。交互式请求面板不保证逐事件展示
