查看事件、会话跟踪和智能体图

<Note>
这些接口使用 `/dev/...` 路径，需要启动开发服务。普通 `adk api_server` 不提供这些接口；启动方式见 [Agent API Server 概览](/productions/api-reference/preview/zh/agent-api-server/overview)
</Note>

| 方法 | 路径 | 接口 |
| --- | --- | --- |
| GET | `/dev/apps/{app_name}/debug/trace/{event_id}` | [获取事件追踪](/productions/api-reference/preview/zh/agent-api-server/get-event-trace) |
| GET | `/dev/apps/{app_name}/users/{user_id}/sessions/{session_id}/events/{event_id}/graph` | [获取事件关联图](/productions/api-reference/preview/zh/agent-api-server/get-event-graph) |
| GET | `/dev/apps/{app_name}/debug/trace/session/{session_id}` | [获取会话追踪](/productions/api-reference/preview/zh/agent-api-server/get-session-trace) |
| GET | `/dev/apps/{app_name}/graph` | [获取智能体图](/productions/api-reference/preview/zh/agent-api-server/get-agent-graph) |
