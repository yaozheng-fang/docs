---
title: "删除评测用例"
openapi: "/productions/api-reference/openapi/zh/harness-runtime.json DELETE /dev/apps/{app_name}/eval-sets/{eval_set_id}/eval-cases/{eval_case_id}"
en_link: "/productions/api-reference/preview/en/harness-runtime/delete-eval-case"
---

<Warning>
此操作从指定评测集中删除一个用例，后续对整个评测集的运行将不再包含该用例。删除前保存需要保留的样本，本接口不提供恢复操作
</Warning>

成功返回 JSON `null`；目标评测集或用例不存在时返回 `404`
