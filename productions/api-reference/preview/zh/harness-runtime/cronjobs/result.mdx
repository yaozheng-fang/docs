---
title: "读取执行结果"
openapi: "/productions/api-reference/openapi/zh/harness-runtime.json GET /harness/cronjobs/{job_id}/runs/{run_id}"
---

需要使用 AgentKit CLI 0.54.0 部署并[启用定时任务](/productions/api-reference/preview/zh/harness-runtime/cronjobs/overview)的 Harness Runtime

响应可以是排队、运行中或终态记录，并非只有完成后才可读取。`output` 保存最终文本；失败时读取 `error`。超时与失败不会自动重试该次执行
