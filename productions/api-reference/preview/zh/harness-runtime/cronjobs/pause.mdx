---
title: "暂停定时任务"
openapi: "/productions/api-reference/openapi/zh/harness-runtime.json POST /harness/cronjobs/{job_id}/pause"
---

需要使用 AgentKit CLI 0.54.0 部署并[启用定时任务](/productions/api-reference/preview/zh/harness-runtime/cronjobs/overview)的 Harness Runtime

暂停会阻止未来执行，并取消仍在排队的执行。已经运行的执行不会被终止，需要使用[取消一次执行](/productions/api-reference/preview/zh/harness-runtime/cronjobs/cancel)单独请求取消
