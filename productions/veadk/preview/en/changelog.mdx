This changelog cumulatively lists all public user-facing changes from VeADK 1.0.0 through the current version. Released versions are ordered newest first.

## 1.1.7

VeADK 1.1.7 was released on August 30, 2026. The following table lists its public user-facing changes. See the [GitHub Release](https://github.com/volcengine/veadk-python/releases/tag/1.1.7) for the complete commit history.

Sub-agents share the same session context and produce the final answer directly. Supports `llm`, `sequential`, `parallel`, and `loop` nodes, plus `workflow` nodes on Google ADK 2.0.0 and above.
