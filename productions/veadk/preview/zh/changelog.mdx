本更新日志累计记录 VeADK 1.0.0 至当前版本的全部公开用户能力变化。尚未发布的变更列在「未发布」分节，已发布版本按从新到旧排列。

## 未发布

| 模块 | 变更细节 | 链接 |
| --- | --- | --- |
| Studio 模型选择 | 自定义创建、智能生成和技能生成中的模型选择按云服务商区分：使用 BytePlus 时仅显示 BytePlus 可用模型，火山引擎模式下显示全部模型；切换云服务商时，Studio 自动将模型和接入地址迁移到对应服务商的默认值。 | [Studio 智能体工作台](/productions/veadk/preview/zh/components/frontend/studio) |
| Studio 知识库 | 自定义创建智能体时，知识库新增 OpenViking 后端，可在创建页配置服务地址、API Key、知识库归属 ID、资源目录和资源索引，并写入生成项目的环境变量。 | [Studio 智能体工作台](/productions/veadk/preview/zh/components/frontend/studio) · [使用 OpenViking 存储](/productions/veadk/preview/zh/components/knowledge/openviking) |

| 技能 | 通过 Harness、CLI 生成的智能体代码或 AgentKit 会话能力服务加载技能时，VeADK 自动为 `SkillToolset` 配置本地代码执行器，技能中的脚本可直接运行，无需额外配置。 | [技能](/productions/veadk/preview/zh/components/agent/skills) |
| Studio 评测 | 自动评测生成的优化项快照改为持久化到 Studio 持久化存储：配置 `VEADK_STUDIO_TOS_BUCKET` 与 `VEADK_STUDIO_TOS_REGION`（部署时自动创建存储桶）时，优化项快照保存在 TOS 中，进程重启后仍然可见并在多个实例间共享；未配置持久化存储时，快照仅保留在进程内存中，重启后丢失。 | [Studio 智能体工作台](/productions/veadk/preview/zh/components/frontend/studio) |
| Studio 部署 | `veadk studio deploy` 在自动创建 Identity 用户池、TOS 存储桶或沙箱 Tool 时，部署成功后额外输出已配置的云资源清单，包括每个沙箱 Tool 的类型与 ID、私有 TOS 存储地址、用户池 ID、客户端 ID 和对应云服务商的 Identity 控制台链接，并提示密码登录默认关闭、需先配置 SSO 身份提供者。 | [Studio 智能体工作台](/productions/veadk/preview/zh/components/frontend/studio) |
| Studio 部署 | `veadk studio deploy` 的 `--user-pool-id` 和 `--allowed-client-id` 改为可选。省略时，部署命令会在 `--region` 指定的地域自动创建或复用同名 VeIdentity 用户池（`veadk-studio-{vefaas-app-name}`）和 Web 客户端（`veadk-studio-{vefaas-app-name}-web`），并在部署完成后回显 Identity 地域、用户池 ID、用户池域名和客户端 ID。同时传入两个参数时仍使用已有资源并按原逻辑跨地域查找。 | [Studio 智能体工作台](/productions/veadk/preview/zh/components/frontend/studio) |
| Studio 部署 | 创建新 Runtime 部署到 AgentKit 时，支持配置镜像构建使用的云资源：TOS 存储桶、容器镜像仓库（CR）和 CodePipeline。每类资源可选自动创建（默认）、指定名称或选择已有；选择已有时由 Studio 服务端加载当前账号的可用资源列表。所选资源记录在 Runtime 标签中，更新已有 Runtime 时保留原有选择。 | [Studio 智能体工作台](/productions/veadk/preview/zh/components/frontend/studio) |
| Studio 技能中心 | 侧边栏新增「技能」页面，提供技能空间管理：按地域和名称浏览技能空间，支持新建、编辑和删除空间。管理员可见全部空间，非管理员仅可见自己创建的空间。每个空间中可上传 ZIP 技能包（至多 20 MiB）、浏览文件树、下载 ZIP 和删除技能。 | [Studio 智能体工作台](/productions/veadk/preview/zh/components/frontend/studio) |
| Studio 技能生成 | 技能中心新增 Dev Sandbox 技能生成：通过 DevEnv Tool 创建独立开发沙箱会话，从自然语言描述生成符合 ADK 格式的技能。支持至多 3 组并行候选方案、模型与风格选择、格式校验自动修复（至多 2 次）、迭代调整以及直接发布到技能空间；还支持对已有技能进行优化并覆盖发布。该能力仅对 `developer` 和 `admin` 角色开放，需要管理员配置 DevEnv Tool。 | [Studio 智能体工作台](/productions/veadk/preview/zh/components/frontend/studio) |
| Studio 对话模式 | 新会话模式选择器移除「创建 Skill」模式，技能创建统一通过技能中心使用 Dev Sandbox 完成。`veadk frontend`、`veadk studio`、`veadk studio deploy` 和 `veadk studio update` 移除 `--sandbox-skill-creator-tool-id`（`--skill-creator-tool-id`）选项和 `SANDBOX_SKILL_CREATOR` 环境变量。 | [Studio 智能体工作台](/productions/veadk/preview/zh/components/frontend/studio) |
| Studio 系统信息 | 账号菜单中的「系统信息」从弹窗改为独立页面，除 Studio 版本外，新增沙箱信息（展示已配置的 Codex、OpenClaw、Hermes 和 Dev Sandbox Tool ID）和用户池信息（展示当前 Studio 关联的 VeIdentity 用户池名称、UID、域名和地域）。该页面仅对具有智能体管理权限的用户开放，资源标识为只读。 | [Studio 智能体工作台](/productions/veadk/preview/zh/components/frontend/studio) |
| Studio 登录 | 使用 BytePlus 作为云服务商并启用 VeIdentity 登录时，登录按钮默认文案改为「BytePlus Identity」；火山引擎模式下仍为「火山引擎 Identity」。显式设置 `--oauth2-provider-label`（或 `OAUTH2_PROVIDER_LABEL`）时始终优先使用自定义文案。 | [Studio 智能体工作台](/productions/veadk/preview/zh/components/frontend/studio) |
| Studio 部署 | 部署进行期间，工作台详情页聚焦于部署进度：保留智能体标题并展示可滚动的部署进度面板，隐藏其余详情标签与内容；部署结束后恢复显示常规详情标签。自定义创建、代码包部署与更新已部署智能体均遵循该行为。 | [Studio 智能体工作台](/productions/veadk/preview/zh/components/frontend/studio) |
| Studio 自动化 | 「配置 Coding Agents」卡片改为仅在通过 `http://127.0.0.1` 访问 Studio 时启用；通过其他主机名（包括 `localhost` 或已部署的 VeFaaS 公网地址）访问时，卡片显示为禁用状态并提示「仅本地部署可用」。 | [Studio 智能体工作台](/productions/veadk/preview/zh/components/frontend/studio) |
| Studio 部署 | 部署成功后，Studio 在自动连接 Runtime 时最多等待 60 秒重试探测端点，减少「部署完成，暂未连接」状态的出现频率。 | [Studio 智能体工作台](/productions/veadk/preview/zh/components/frontend/studio) |
| Studio 部署 | 部署失败或取消后，进度卡片新增「返回编辑」按钮，可直接回到草稿调整配置后重新发起部署。 | [Studio 智能体工作台](/productions/veadk/preview/zh/components/frontend/studio) |
| Studio 技能生成 | 技能生成工作台改进界面布局：新增「基本信息」分区，「目标」字段标记为必填；「生成配置」改为「生成方案」（优化时为「优化方案」），各方案中的模型与风格标记为必填项。 | [Studio 智能体工作台](/productions/veadk/preview/zh/components/frontend/studio) |
| Studio 技能中心 | 技能中心创建入口由「Dev Sandbox 创建」改为「自动创建」，空状态提示同步更新。 | [Studio 智能体工作台](/productions/veadk/preview/zh/components/frontend/studio) |
| Studio 沙箱 | `--sandbox-dev-tool-id` 和 `SANDBOX_DEV` 环境变量不再限于火山引擎部署，BytePlus 部署和更新现在同样支持 Dev Sandbox：部署时自动创建 DevEnv Tool，更新时检测缺失并自动修复。 | [Studio 智能体工作台](/productions/veadk/preview/zh/components/frontend/studio) |
| Studio 视频创作 | 新会话页面新增「视频创作」工作区模式：根据文本提示和可选的参考素材生成视频，支持文生视频、参考素材生视频、视频编辑、视频续写和首尾帧生成等任务模式，可配置画面比例、分辨率和时长；生成过程分为提示词优化和视频生成两个阶段，完成后可预览和下载。火山引擎使用 `doubao-seedance-2-5-260628` 生成模型与 `doubao-seed-2-1-pro-260628` 增强模型，BytePlus 使用 `dreamina-seedance-2-5-260628` 与 `dola-seed-2-1-turbo-260628`。 | [Studio 智能体工作台](/productions/veadk/preview/zh/components/frontend/studio) |
| Studio 技能定制 | 新会话页面新增「技能定制」工作区模式，提供技能生成和技能优化的快捷入口，复用技能中心 Dev Sandbox 技能生成能力。该模式仅对 `developer` 和 `admin` 角色开放，且仅在管理员配置可用 Dev Sandbox 后显示。 | [Studio 智能体工作台](/productions/veadk/preview/zh/components/frontend/studio) |
| Studio 持久化存储 | 视频创作等能力新增 Studio 持久化存储：`veadk studio deploy` 部署时自动创建或复用名为 `veadk-studio-<账号 ID>` 的私有 TOS 存储桶；本地启动通过 `VEADK_STUDIO_TOS_BUCKET` 与 `VEADK_STUDIO_TOS_REGION` 环境变量配置。参考素材上传和生成结果保存依赖该存储。 | [Studio 智能体工作台](/productions/veadk/preview/zh/components/frontend/studio) |
| Studio 系统信息 | 系统信息页面访问权限由「智能体管理权限」收紧为仅 `admin` 角色可访问，并新增「存储」分区展示 Studio 持久化存储的 TOS 地址。 | [Studio 智能体工作台](/productions/veadk/preview/zh/components/frontend/studio) |

## 1.1.0

VeADK 1.1.0 发布于 2026 年 8 月 7 日。下表列出该版本的公开用户能力变化；完整提交记录见 [GitHub Release](https://github.com/volcengine/veadk-python/releases/tag/1.1.0)。

| Studio 云服务商 | `veadk studio`、`veadk frontend`、`veadk studio deploy` 和 `veadk studio update` 新增 `--provider` 选项，可选择 `volcengine`（默认）或 `byteplus`；选择 BytePlus 时使用 `BYTEPLUS_ACCESS_KEY`、`BYTEPLUS_SECRET_KEY` 和可选的 `BYTEPLUS_SESSION_TOKEN` 提供凭证，Runtime 列表默认地域为 `BYTEPLUS_REGION` 或 `ap-southeast-1`。`veadk studio deploy` 和 `veadk studio update` 新增 `--byteplus-access-key`、`--byteplus-secret-key` 和 `--byteplus-session-token` 选项。 | [Studio 智能体工作台](/productions/veadk/preview/zh/components/frontend/studio) · [VeADK Frontend](/productions/veadk/preview/zh/components/frontend/veadk-frontend) |
