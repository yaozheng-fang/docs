This changelog cumulatively lists all public user-facing changes from VeADK 1.0.0 through the current version. Released versions are ordered newest first.

## 1.1.3

VeADK 1.1.3 was released on August 20, 2026. The following table lists its public user-facing changes. See the [GitHub Release](https://github.com/volcengine/veadk-python/releases/tag/1.1.3) for the complete commit history.
