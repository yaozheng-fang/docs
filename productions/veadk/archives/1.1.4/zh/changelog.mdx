本更新日志累计记录 VeADK 1.0.0 至当前版本的全部公开用户能力变化，已发布版本按从新到旧排列。

## 1.1.4

VeADK 1.1.4 发布于 2026 年 8 月 20 日。下表列出该版本的公开用户能力变化；完整提交记录见 [GitHub Release](https://github.com/volcengine/veadk-python/releases/tag/1.1.4)。

| 模块 | 变更细节 | 链接 |
| --- | --- | --- |
| Studio GitHub 交付 | 新增通过 GitHub 交付智能体的能力：在自定义创建的部署配置区选择「GitHub 代码同步」将生成的源码推送到目标分支（Runtime 仍由部署按钮发布），或选择「挂载持续交付」在目标分支写入 AgentKit Runtime 的 GitHub Actions 工作流，后续推送代码自动构建并发布到绑定的 Runtime；部署时新增「挂载 GitHub 持续交付」阶段并展示挂载日志。 | [Studio 智能体工作台](/productions/veadk/preview/zh/components/frontend/studio) |
| Studio 版本管理 | 绑定 GitHub 持续交付的 Runtime 详情页新增「版本」标签，列出目标分支提交历史与工作流运行记录及发布状态，支持选择历史版本创建回退：已挂载持续交付时自动合并回退 PR 并触发发布，仅代码同步时创建回退 PR 等待人工合并。 | [Studio 智能体工作台](/productions/veadk/preview/zh/components/frontend/studio) |
| 命令行 | 新增 `veadk github-cicd-pipeline` 命令，将 Studio 导出的 AgentProject JSON 推送到目标 GitHub 分支，对应代码同步模式。 | [Studio 智能体工作台](/productions/veadk/preview/zh/components/frontend/studio) |
| 依赖 | 新增 `github-cicd` 可选依赖组（PyNaCl），用于 Studio 挂载持续交付时加密写入 GitHub Actions Secret。 | [安装](/productions/veadk/preview/zh/get-started/installation) |
| 依赖 | 放宽 `a2a-sdk` 版本约束为 `>=0.3.7,<1.0.0`，允许安装更高版本的 A2A 协议 SDK。 | [安装](/productions/veadk/preview/zh/get-started/installation) |

## 1.1.3

VeADK 1.1.3 发布于 2026 年 8 月 20 日。下表列出该版本的公开用户能力变化；完整提交记录见 [GitHub Release](https://github.com/volcengine/veadk-python/releases/tag/1.1.3)。
