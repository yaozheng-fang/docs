AgentKit CLI commands are organized into groups; each group has its own page
below, listing options and examples per command. Run `agentkit tree` any time to
print the full command tree (`--all` expands args and options, `--json` for
machine-readable output).

## Global options

Place global options before the subcommand. They apply to the current command.

| Option | Default | Description |
| --- | --- | --- |
| `-v, --version` | - | Print the current CLI version and exit. |
| `--provider <provider>` | Not set | Override the cloud provider for the current command. Valid values are `volcengine` and `byteplus`. |

The provider is resolved in this order: `--provider`, `AGENTKIT_CLOUD_PROVIDER`, `CLOUD_PROVIDER`, project configuration, user-level defaults, then `volcengine`.

```bash
agentkit --version
agentkit --provider byteplus runtime list
```
