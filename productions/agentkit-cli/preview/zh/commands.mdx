AgentKit CLI 的命令按组组织，下方每一组单独成篇，逐个命令列出选项与示例。随时运行 `agentkit tree` 可打印完整命令树（`--all` 展开参数与选项，`--json` 输出机器可读格式）。

## 全局选项

全局选项写在子命令之前，对当前命令生效。

| 选项 | 默认值 | 说明 |
| --- | --- | --- |
| `-v, --version` | - | 输出当前 CLI 版本并退出。 |
| `-h, --help` | `false` | 显示当前命令帮助并退出；`invoke run` 使用 `--help`，其 `-h` 为请求头选项 |
| `--provider <provider>` | 未设置 | 覆盖当前命令使用的云厂商，可选值为 `volcengine` 或 `byteplus`。 |
| `--no-auto-login` | `false` | 缺少云凭据时直接失败，不启动浏览器登录 |

云厂商按以下顺序确定：`--provider`、`AGENTKIT_CLOUD_PROVIDER`、`CLOUD_PROVIDER`、项目配置、用户级默认配置，最后回退到 `volcengine`。

```bash lines
agentkit --version
agentkit --provider byteplus runtime list
```
