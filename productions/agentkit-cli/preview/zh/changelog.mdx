## 0.52.8 - 2026-08-26

- [skills 命令] [`skills secure`](/productions/agentkit-cli/preview/zh/commands/skill#skills-secure) 可从本地技能目录批量生成面向托管智能体安装的安全壳 Skill，保留 `name` 与 `description`，但不复制真实 Skill 的 Prompt、references、scripts、依赖或凭证。
- [沙箱命令] [Claude 自托管沙箱流程](/productions/agentkit-cli/preview/zh/commands/sandbox#sandbox-init) 改为以 `.agentkit/sandbox.yaml` 作为配置来源：`sandbox init -t self-host` 不再生成 dotenv 模板，`sandbox create` 会创建 `Private` Tool 并写入 `self_host.sandbox.id` 与 `self_host.sandbox.name`，随后 [`env create`](/productions/agentkit-cli/preview/zh/commands/env#env-create) 只创建绑定该 Tool 的 Runtime，并可用 `--tool-id` 覆盖 Tool ID。
- [沙箱命令] [`sandbox create --network-private`](/productions/agentkit-cli/preview/zh/commands/sandbox#sandbox-create) 在缺少完整 VPC 与子网配置时会交互式选择当前区域下的 VPC 和可用子网，并把选择结果写回 `.agentkit/sandbox.yaml`。
- [沙箱命令] [`sandbox config`](/productions/agentkit-cli/preview/zh/commands/sandbox#sandbox-config) 提供 self-host 配置键，并在 `--list` 输出中隐藏 `self-host-environment-key`；非自托管沙箱的 `tool-id` / `tool-name` 配置会统一写入 `tool_info`，便于后续命令稳定复用 Tool 绑定信息。

## 0.52.7 - 2026-08-25

- [env 命令] [`env`](/productions/agentkit-cli/preview/zh/commands/env) 命令组面向 Claude 自托管沙箱环境。项目完成 `sandbox build` 后，可通过 `env create` 基于构建镜像与 `.env` 创建 Private Tool 和调度 Runtime，并用 `env status` 刷新本地环境状态。
- [沙箱命令] [`sandbox init -t self-host`](/productions/agentkit-cli/preview/zh/commands/sandbox#sandbox-init) 支持初始化 Claude 自托管沙箱项目，生成 Dockerfile、`.env`、`.env.example`、忽略文件、README 和 `.agentkit/sandbox.yaml`；`sandbox build` 会读取构建配置并写入镜像地址与构建状态，供 `env create` 使用。
- [init 命令] [`init --from-agent`](/productions/agentkit-cli/preview/zh/commands/init) 支持 `agent_server` 包装类型，并可通过 `--template basic|basic_stream|agent_server` 选择兼容的包装模板；模板与 `--wrapper-type` 不匹配时会立即停止执行。
- [Harness Sidecar] [托管 Harness Sidecar 配置](/productions/agentkit-cli/preview/zh/agentkit-yaml#harness-sidecar) 改为按解析后的组件计划决定模型代理是否启用；MCP-only 计划可只启用 MCP 网关，发布校验也只检查实际启用的网关。
- [Harness Sidecar] [`release build`](/productions/agentkit-cli/preview/zh/commands/release#release-build) 在托管 Sidecar 场景下会校验显式指定的 Code Pipeline 是否兼容当前构建契约，未找到或不兼容时直接失败；托管基础镜像中的 SDK、ADK、MCP 与 Starlette 版本边界也会在构建中校验。
- [runtime 命令] [`runtime show --json`](/productions/agentkit-cli/preview/zh/commands/runtime#runtime-show) 在运行时绑定 Tool 时返回 `toolId`，便于脚本关联 Runtime 与 Tool。

## 0.52.6 - 2026-08-20

- [配置] [生命周期配置](/productions/agentkit-cli/preview/zh/agentkit-yaml#云端与混合策略) 中的 `runtime_network.mode: hybrid` 会同时启用公网入口和私有网络，避免混合网络运行时在部署后只保留公网访问。

## 0.52.5 - 2026-08-20

- [配置] [`config --init`](/productions/agentkit-cli/preview/zh/commands/config#config) 会把同一条命令中的项目级参数写入新建的 `agentkit.yaml`，便于在非交互环境中一次性生成完整生命周期配置。
- [配置] [`config`](/productions/agentkit-cli/preview/zh/commands/config#config) 补充生命周期配置字段的帮助说明；交互式向导会根据终端宽度收敛选项表格，减少窄终端中的换行溢出。
- [沙箱命令] [模型环境变量](/productions/agentkit-cli/preview/zh/commands/sandbox#模型环境变量) 统一注入 Codex、OpenCode 与 `MODEL_AGENT_*` 模型环境变量，并停止为通用模型参数生成 `ANTHROPIC_*`、`CODEX_CONFIG_TOML` 与 `CODEX_MODEL_CATALOG_JSON` 环境变量，减少不同编码智能体和运行时之间的配置差异。
- [沙箱命令] [`sandbox exec`](/productions/agentkit-cli/preview/zh/commands/sandbox#sandbox-exec) 在已有 `CodeEnv` 会话中显式更新模型名称、API Key 或 Base URL 时，会同步写入会话内的 `.env`、Codex 配置和 OpenCode 配置，后续终端可以复用同一组设置。
- [沙箱命令] [`sandbox codex-login`](/productions/agentkit-cli/preview/zh/commands/sandbox#sandbox-codex-login) 在沙箱会话内直接写入 Codex OAuth 配置，再注入本地订阅凭据，使订阅登录配置不依赖会话环境变量传递。

## 0.52.4 - 2026-08-19

- [memory 命令] [`memory create`](/productions/agentkit-cli/preview/zh/commands/memory#memory-create) 在 BytePlus 上默认创建 `VIKINGDB_MEMORY` 记忆库，并在显式或通过 `--json` 传入 `MEM0` 时提前失败；Volcengine 默认仍为 `MEM0`。
- [migrate 命令] [Dify 迁移](/productions/agentkit-cli/preview/zh/commands/migrate#dify-迁移范围) 改为按 YAML 内容识别 Dify DSL，可处理任意文件名和子目录中的 Dify 导出，同时避免把同名普通 YAML 误判为 Dify。
- [Harness Sidecar] [发布构建](/productions/agentkit-cli/preview/zh/commands/release#release-build) 优化托管 Harness Sidecar 构建：使用符合当前结构的 CLI 托管 Dockerfile，按托管基础镜像摘要隔离并启用 Code Pipeline 缓存，并根据归档大小调整 TOS 上传超时。
- [Harness Sidecar] [`harness sidecar resolve`](/productions/agentkit-cli/preview/zh/commands/harness#harness-sidecar-resolve) 在 `ops` profile 关闭 `mcp_resilience` 时输出 SQL 只读保护已关闭的警告，便于发布前识别风险选择。

## 0.52.3 - 2026-08-18

- [沙箱命令] [`sandbox list`](/productions/agentkit-cli/preview/zh/commands/sandbox#sandbox-list) 可查看沙箱会话或工具：默认读取本地会话缓存，支持 `--tools` 查看工具缓存，支持 `--remote` 查询远端工具或指定工具下的远端会话，并可按工具 ID、名称、类型和状态过滤。
- [Harness Sidecar] [托管 Harness Sidecar 发布](/productions/agentkit-cli/preview/zh/commands/release#release-apply) 提升发布恢复能力：运行时进入 `Ready` 后会等待 `key_auth` APIG 绑定；发布接口结果不明确但已观察到运行时进入发布流程或新版本就绪时，CLI 会继续完成流程，避免重复触发发布。
- [Harness Sidecar] [托管 Harness Sidecar 运行时恢复](/productions/agentkit-cli/preview/zh/commands/release#release-apply) 在当前版本仍是唯一可服务版本且所有更新版本均失败时，可保留当前服务版本并原地更新；无法确认安全恢复条件时会失败并要求显式处理。
- [Harness Sidecar] [发布构建](/productions/agentkit-cli/preview/zh/commands/release#release-build) 在托管 Sidecar 场景下保留应用声明的 `veadk-python` 与 `agentkit_sdk_python` 依赖，移除已废弃的 `agentkit-harness-sidecar-integration` 独立包，并将 TOS 构建上下文上传调整为 120 秒超时与一次可重试网络错误重试。

## 0.52.2 - 2026-08-14

- [chat 命令] [`chat`](/productions/agentkit-cli/preview/zh/commands/chat) 可通过租户登录发现文档中的共享 Harness 别名发起 OAuth 绑定聊天，并按已验证用户身份隔离会话。
- [eval 命令] [eval backend](/productions/agentkit-cli/preview/zh/commands/eval/backend) 默认使用 AgentKit 评测网关解析 Coze 或 TEA 后端，并提供 `--cache-refresh` 与 `--verbose`，便于查看后端坐标和排查 TEA 请求。

- [eval 命令] [`eval run`](/productions/agentkit-cli/preview/zh/commands/eval/run) 支持指定 TEA 评测集版本、评估器版本、源评测目标类型和目标版本，并在结果中返回 TEA run ID。
- [Harness] [Harness 配置](/productions/agentkit-cli/preview/zh/commands/harness) 支持共享 OAuth Harness 的私有网络、容量、共享数据库会话和托管模型出口，并在部署后校验身份、镜像与扩缩容绑定。
- [invoke 命令] [`invoke run`](/productions/agentkit-cli/preview/zh/commands/invoke#custom_jwt-鉴权) 调用 `custom_jwt` Runtime 时不再自动复用登录会话中的 `id_token`；通用调用需要通过 `--headers` 显式传入 OAuth token，共享 OAuth Harness 的受控聊天入口改用 `chat`。
- [沙箱命令] [`sandbox create`](/productions/agentkit-cli/preview/zh/commands/sandbox#sandbox-create) 提供 `--llm-shield-app-id`，可为 `Skill` 沙箱工具启用 LLM Shield。

## 0.52.0 - 2026-08-11
