`tree` 命令打印 CLI 的完整命令树，可选择展开每个命令的参数与选项，或以机器可读的 JSON 格式输出。

## tree

打印完整的命令树。

| 标志/参数 | 说明 | 默认值 |
| --- | --- | --- |
| `--json` | 以 JSON 格式输出命令树 | `false` |
| `-a, --all` | 同时展开每个命令的参数与选项 | `false` |

```bash lines
agentkit tree --all
```

命令树来自本机已安装版本，不需要云账号或项目配置。排查选项不存在时，先检查 `agentkit --version`，再查看目标命令的 `--help`

需要保存命令清单供脚本读取时：

```bash lines
agentkit tree --all --json > command-tree.json
```

输出文件包含命令名称、别名、位置参数、选项与子命令；它描述命令结构，不包含云端资源列表
