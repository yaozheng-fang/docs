`agentkit docs` 在系统默认浏览器中打开 AgentKit CLI 的在线文档。当前环境无法启动浏览器时（例如无图形界面或持续集成环境），改为在终端打印文档链接。

## docs

| 标志/参数 | 说明 | 默认值 |
| --- | --- | --- |
| `--print` | 仅打印文档链接，不打开浏览器。 | `false` |

```bash lines
agentkit docs
agentkit docs --print
```

此命令不要求登录或项目配置。`--print` 适合远程终端，输出的 URL 可复制到有浏览器的设备打开；查看本机版本的参数应使用 `agentkit <command> --help`，在线 Preview 可能包含不同版本的说明
