`memory` 命令组用于管理 AgentKit 记忆库，涵盖列表、详情查看、创建、更新与删除等操作。该命令同时提供 `mem` 别名。

记忆库是保存和检索长期记忆的云端资源，创建资源本身不会自动让智能体写入记忆。需要在智能体或运行时配置中关联创建结果返回的记忆库 ID，并使用同一云厂商与区域的凭证

<Warning>
创建记忆库可能产生云资源费用；写入的对话和用户信息会由所选记忆服务保存。删除前检查关联智能体并保留必要数据，`--yes` 会跳过删除确认
</Warning>

## memory list

列出所有记忆库。

| 标志/参数 | 说明 | 默认值 |
| --- | --- | --- |
| `-r, --region <region>` | 云区域。 | 自动检测 |
| `-p, --project <name>` | 项目名称。 | default |
| `--json` | 输出原始 JSON。 | `false` |

```bash lines
agentkit memory list --project demo
```

## memory show

查看记忆库的详情。

| 标志/参数 | 说明 | 默认值 |
| --- | --- | --- |
| `<id>` | 记忆库 id，例如 `m-xxxxxxxx`。必填。 | — |
| `-r, --region <region>` | 云区域。 | 自动检测 |
| `--json` | 输出原始 JSON。 | `false` |

```bash lines
agentkit memory show m-12345678
```

## memory create

创建记忆库。

| 标志/参数 | 说明 | 默认值 |
| --- | --- | --- |
| `--name <name>` | 记忆库名称。 | — |
| `--description <text>` | 描述。 | — |
| `-p, --project <name>` | 项目名称。 | default |
| `--provider-type <type>` | 提供方类型（`MEM0` \| `VIKINGDB_MEMORY`）。 | Volcengine 为 `MEM0`，BytePlus 为 `VIKINGDB_MEMORY` |
| `-r, --region <region>` | 云区域。 | 来自当前云厂商或环境变量 |
| `--json <jsonString>` | 合并进请求体的 JSON 对象（用于 `LongTermConfiguration`、`VpcConfig`、`Tags` 等嵌套字段）。 | — |

```bash lines
agentkit memory create --name user-mem --provider-type MEM0

agentkit --provider byteplus memory create \
  --name user-mem \
  --provider-type VIKINGDB_MEMORY
```

`--provider-type` 的值会按大小写规范化。BytePlus 不支持创建 `MEM0` 记忆库；显式传入 `--provider-type MEM0`，或在 `--json` 中把 `ProviderType` 覆盖为 `MEM0`，都会在请求发出前失败。

## memory update

更新记忆库。

| 标志/参数 | 说明 | 默认值 |
| --- | --- | --- |
| `<id>` | 记忆库 id，例如 `m-xxxxxxxx`。必填。 | — |
| `--description <text>` | 新的描述。 | — |
| `-r, --region <region>` | 云区域。 | 自动检测 |
| `--json <jsonString>` | 合并进请求体的 JSON 对象（用于 `LongTermConfiguration`、`VpcConfig` 等嵌套字段）。 | — |

```bash lines
agentkit memory update m-12345678 --description "更新后的记忆"
```

## memory delete

删除记忆库。

| 标志/参数 | 说明 | 默认值 |
| --- | --- | --- |
| `<id>` | 记忆库 id，例如 `m-xxxxxxxx`。必填。 | — |
| `-r, --region <region>` | 云区域。 | 自动检测 |
| `-y, --yes` | 跳过确认提示。 | `false` |

```bash lines
agentkit memory delete m-12345678 --yes
```

创建或更新后，使用返回的 ID 执行 `agentkit memory show <id> --json` 核对配置。若资源可查但智能体无法保存记忆，检查运行时关联的记忆库 ID、运行时权限与所选提供方配置；管理资源成功不代表应用的记忆读写已验证
