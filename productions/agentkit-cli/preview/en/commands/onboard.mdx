The `onboard` command installs the CLI's bundled agent skills into coding agents (Claude Code, Codex, Trae).

## onboard

Install the bundled agent skills into coding agents.

| Flag / Argument | Description | Default |
| --- | --- | --- |
| `-a, --agent <ids>` | Comma-separated targets: `claude-code`, `codex`, `trae` | None |
| `--all` | Install into all supported agents | `false` |
| `-s, --scope <scope>` | Install scope: `project` \| `global` | None |
| `-y, --yes` | Non-interactive: use detected agents + default scope | `false` |

```bash lines
agentkit onboard --agent claude-code --scope project
```

## Scope and result

`project` is relative to the working directory; `global` is relative to your home directory. Omitting `--scope` opens a prompt, while `--yes` defaults to `project`. Specify both the target and scope in automation:

```bash lines
agentkit onboard --agent claude-code --scope project --yes
```

The command lists the skill directories it writes. Reinstalling overwrites matching skill files, so preserve local changes first. Without `--agent` or `--all`, `--yes` selects only detected clients; if none are detected, it fails instead of installing for every client

The command copies bundled skills. It does not install a client or sign in to a cloud platform
