---
title: "Use sandboxes"
---

The `sandbox` command group creates and manages AgentKit sandbox tools, then runs commands, invokes A2A agents, transfers files, opens web previews, and injects local model login credentials in sandbox sessions. Current sandbox tool types are `CodeEnv`, `SkillEnv`, and `Private`; sessions are named with `-s, --session-id <id>`, with alias `--sid <id>`.

<Note>
Sandbox commands use CLI flags first, then defaults from `.agentkit/sandbox.yaml`. After `sandbox create` succeeds, it writes the created `tool-id` and `tool-name` to that config file; later `exec`, `shell`, `web`, `invoke`, `mount`, and login injection commands can reuse those defaults. When no sandbox tool is configured, some commands prompt to create a default tool; in non-interactive environments, run `agentkit sandbox create` first or pass `--tool-id` / `--tool-name` explicitly.

Defaults in the tables below describe behavior when neither a CLI flag nor the corresponding `.agentkit/sandbox.yaml` value is set.
</Note>

## sandbox init

Generate a Dockerfile template for a custom sandbox image.

| Flag / Argument | Description | Default |
| --- | --- | --- |
| `-t, --template <name>` | Dockerfile template. Supported values: `skill`, `skills`, `aio`, `code`, `code-install-package`, `code-install-skills`, `code-web-server`. | `skill` |
| `-o, --output <path>` | Output Dockerfile path. | Template default path |
| `-f, --force` | Overwrite an existing Dockerfile. | `false` |

```bash
agentkit sandbox init --template code-web-server --output Dockerfile.sandbox --force
```

## sandbox build

Build a custom sandbox image in cloud Code Pipeline, then write the resulting image URL to `.agentkit/sandbox.yaml` and set `tool-type` to `Private`.

<Warning>
`sandbox build` uploads the build context, creates or reuses TOS, Container Registry, and Code Pipeline resources, and may incur cloud charges. Confirm the current project directory, Dockerfile, region, and account permissions before running it.
</Warning>

| Flag / Argument | Description | Default |
| --- | --- | --- |
| `--dockerfile <path>` | Dockerfile path relative to the project directory. | `Dockerfile` |
| `--image-name <name>` | Container Registry image name, mapped to the CR repository name. | `agentkit-custom-sandbox-image` |
| `--repo <name>` | Container Registry image name, mapped to the CR repository name; same effect as `--image-name`. | `agentkit-custom-sandbox-image` |
| `--tag <tag>` | Container image tag; may contain the `{{timestamp}}` placeholder. | `{{timestamp}}` |
| `--namespace <name>` | Container Registry namespace. | `agentkit` |
| `--project-dir <path>` | Project directory to package as the Docker build context. | Current directory |

```bash
agentkit sandbox build \
  --dockerfile Dockerfile.sandbox \
  --image-name team-code-sandbox \
  --tag dev-{{timestamp}}
```

## sandbox config

Configure local defaults for sandbox commands. The config file is `.agentkit/sandbox.yaml` in the current project.

| Flag / Argument | Description | Default |
| --- | --- | --- |
| `--set <KEY=VALUE>` | Set a config value; repeatable. | — |
| `--unset <KEY>` | Remove a config value; repeatable. | — |
| `--list` | Print the effective config with sensitive values redacted. | `false` |

Supported config keys:

| Key | Type | Default | Description |
| --- | --- | --- | --- |
| `model-name` | string | Inferred from `model-provider` | Model name injected into sandbox sessions or tools. |
| `model-provider` | string | `model_square` on Volcengine, `byteplus_model_square` on BytePlus | Model provider. |
| `model-base-url` | string | Inferred from `model-provider` | Model API base URL; non-built-in Ark URLs also require `model-provider`. |
| `model-api-key` | string | — | Model API key. |
| `network-public` | boolean | `true` | Enable public network access when creating a tool. |
| `network-private` | boolean | `false` | Enable private VPC networking when creating a tool. |
| `network-shared-internet` | boolean | `false` | Enable shared internet access for private networking. |
| `network-vpc-id` | string | — | VPC ID for private networking. |
| `network-subnet-ids` | string list | — | Subnet IDs, as CSV or a JSON array. |
| `tool-type` | enum | `CodeEnv` | Sandbox tool type: `CodeEnv`, `SkillEnv`, or `Private`. |
| `tool-id` | string | — | Default sandbox tool ID. |
| `tool-name` | string | — | Default sandbox tool name. |
| `region` | string | Platform default region | AgentKit control-plane region. |
| `cpu` | integer | `4` | vCPU count when creating a tool. Supported values: `2`, `4`, `8`, `16`. |
| `tos-bucket` | string | — | TOS bucket to mount when creating a tool. |
| `tos-mount` | string | `/home/gem/workspace` | Mount path inside the sandbox. |
| `role-name` | string | — | IAM role name used for sandbox skills. |
| `enable-snapshot` | boolean | `false` | Enable snapshot support when creating a tool. |
| `websearch-apikey` | string | — | Injected as `WEB_SEARCH_API_KEY`. |
| `image-url` | string | — | Custom image URL for `Private` tools. |
| `tool-image-url` | string | — | Alias for `image-url`. |
| `session-id` | string | — | Default user session ID. |
| `ttl` | integer | `28800` | Session TTL in seconds. |
| `git-config` | string | — | Git identity source to inject: `local` or an INI/TOML/JSON file. |

```bash
agentkit sandbox config \
  --set tool-type=CodeEnv \
  --set cpu=4 \
  --set model-provider=model_square \
  --set session-id=dev \
  --list
```

## sandbox create

Create a sandbox tool. Use `CodeEnv` for coding sessions, `SkillEnv` for A2A skill invocation, and `Private` for a custom image.

<Warning>
`sandbox create` provisions cloud compute resources that may incur charges while they exist. Confirm the tool type, size, network settings, TOS mount, and image source before creating one. Delete unused tools with `sandbox delete --tool-id <id> --force`.
</Warning>

| Flag / Argument | Description | Default |
| --- | --- | --- |
| `--tool-type <type>` | Tool type: `CodeEnv`, `SkillEnv`, or `Private`. | `CodeEnv` |
| `--tool-name <name>` | Tool name. | Auto-generated |
| `--tos-bucket <bucket>` | TOS bucket to mount. | — |
| `--tos-mount <path>` | Mount path inside the sandbox. | `/home/gem/workspace` |
| `--cpu <count>` | vCPU count: `2`, `4`, `8`, or `16`; memory is 2048 MB per vCPU. | `4` |
| `--model-name <name>` | Model name to inject. | Inferred from the model provider |
| `--model-api-key <key>` | Model API key to inject. | `MODEL_API_KEY` environment variable or — |
| `--model-provider <provider>` | Model provider. | Inferred from the cloud provider |
| `--model-base-url <url>` | Model API base URL; non-built-in Ark URLs also require `--model-provider`. | Inferred from the model provider |
| `--skill-role-name [roleName]` | Configure an IAM role for sandbox skills; omit the value to auto-generate a role name. Mutually exclusive with `--websearch-apikey`. | — |
| `--websearch-apikey <key>` | Inject a Web Search API key. Mutually exclusive with `--skill-role-name`. | — |
| `--image-url <url>` | Custom image URL; required with `--tool-type Private`. | — |
| `--enable-snapshot` | Enable snapshot support. | `false` |
| `--network-public` / `--no-network-public` | Enable or disable public network access. | `true` |
| `--network-private` / `--no-network-private` | Enable or disable private VPC networking. | `false` |
| `--network-shared-internet` / `--no-network-shared-internet` | Enable or disable shared internet access for private networking. | `false` |
| `--network-vpc-id <id>` | VPC ID for private networking; required when `--network-private` is enabled. | — |
| `--network-subnet-ids <ids>` | Comma-separated subnet IDs. | — |
| `--json` | Output JSON. | `false` |

```bash
agentkit sandbox create \
  --tool-type CodeEnv \
  --tool-name dev-code \
  --cpu 4 \
  --model-provider model_square
```

Create a custom-image sandbox:

```bash
agentkit sandbox create \
  --tool-type Private \
  --tool-name private-code \
  --image-url registry.example.com/team/code-sandbox:latest
```

## sandbox delete

Delete a sandbox tool, or delete a session under a tool when a session ID is provided.

<Warning>
Deleting a tool or session cannot be undone. Confirm `--tool-id` / `--tool-name` and `--session-id`, and save required files with `sandbox scp` before deleting.
</Warning>

| Flag / Argument | Description | Default |
| --- | --- | --- |
| `-s, --session-id <id>, --sid <id>` | User session ID to delete; omit it to delete the tool itself. | — |
| `--tool-id <id>` | Sandbox tool ID; mutually exclusive with `--tool-name`. | — |
| `--tool-name <name>` | Sandbox tool name; mutually exclusive with `--tool-id`. | — |
| `--force` | Skip the confirmation prompt. | `false` |

```bash
agentkit sandbox delete --tool-id tool-123456 --force
agentkit sandbox delete --tool-id tool-123456 --session-id dev --force
```

## sandbox list

List locally cached sandbox sessions, or look up a specific cached session.

| Flag / Argument | Description | Default |
| --- | --- | --- |
| `-s, --session-id <id>, --sid <id>` | User session ID to look up. | — |
| `--tool-id <id>` | Filter the local session cache by sandbox tool ID. | — |

```bash
agentkit sandbox list
agentkit sandbox list --tool-id tool-123456 --session-id dev
```

## sandbox exec

Connect to a sandbox session and execute a command; omit `--command` to open an interactive terminal. The command creates or reuses a session and can upload local files, inject Git identity, and inject model configuration before execution.

| Flag / Argument | Description | Default |
| --- | --- | --- |
| `-s, --session-id <id>, --sid <id>` | User session ID. | Config `session-id` or generated |
| `--tool-id <id>` | Sandbox tool ID. | Config `tool-id` |
| `--tool-name <name>` | Sandbox tool name, used to resolve a tool when `tool-id` is unset. | Config `tool-name` |
| `--tool-type <type>` | Sandbox tool type. | `CodeEnv` |
| `--command <cmd>` | Command to run in the sandbox; omit to only connect the terminal. | — |
| `--mode <mode>` | Execution mode; the only supported value is `tmux`, which attaches to or creates a same-named tmux session. | — |
| `--shell-id <id>` | Remote terminal shell ID to reconnect. | — |
| `--copy <sourceAndDestination...>` | Upload local `SOURCE` to sandbox `DESTINATION` before execution, passed as pairs and repeatable. | — |
| `--git-config <source>` | Git identity source: `local` or an INI/TOML/JSON file. | Config `git-config` |
| `--model-name <name>` | Model name to inject. | Config `model-name` |
| `--model-api-key <key>` | Model API key to inject. | Config `model-api-key` or `MODEL_API_KEY` |
| `--model-provider <provider>` | Model provider to inject. | Config `model-provider` |
| `--model-base-url <url>` | Model API base URL to inject. | Config `model-base-url` |
| `--disable-websearch-apikey` | Clear `WEB_SEARCH_API_KEY` for this session. | `false` |

```bash
agentkit sandbox exec \
  --session-id dev \
  --tool-name dev-code \
  --copy ./app sandbox:app \
  --command "cd /home/gem/app && npm test"
```

Open a persistent tmux session:

```bash
agentkit sandbox exec --session-id dev --mode tmux --command "codex"
```

## sandbox shell

Execute a single command in a sandbox shell and print the JSON result. Use `shell` for short commands; use `sandbox exec` for sustained interaction.

| Flag / Argument | Description | Default |
| --- | --- | --- |
| `-s, --session-id <id>, --sid <id>` | User session ID. | Config `session-id` or generated |
| `--tool-id <id>` | Sandbox tool ID. | Config `tool-id` |
| `--tool-name <name>` | Sandbox tool name. | Config `tool-name` |
| `--tool-type <type>` | Sandbox tool type. | `CodeEnv` |
| `--command <cmd>` | Command to execute; required. | — |
| `--exec-dir <dir>` | Execution directory. | — |
| `--copy <sourceAndDestination...>` | Upload local `SOURCE` to sandbox `DESTINATION` before running the command. | — |
| `--git-config <source>` | Git identity source: `local` or an INI/TOML/JSON file. | Config `git-config` |

```bash
agentkit sandbox shell \
  --session-id dev \
  --command "pwd && ls -la" \
  --exec-dir /home/gem
```

## sandbox scp

Copy one file or directory between local storage and a cached sandbox session. Sandbox paths must start with `sandbox:`; relative sandbox paths are resolved under `/home/gem`.

| Flag / Argument | Description | Default |
| --- | --- | --- |
| `<source>` | Source path: a local path or `sandbox:<path>`. | — |
| `<destination>` | Destination path: a local path or `sandbox:<path>`. | — |
| `-s, --session-id <id>, --sid <id>` | User session ID used for the transfer; required. | — |
| `--tool-id <id>` | Sandbox tool ID used to disambiguate the local session cache. | — |

```bash
agentkit sandbox scp ./local.txt sandbox:workspace/local.txt --session-id dev
agentkit sandbox scp sandbox:/home/gem/workspace/report.json ./report.json --session-id dev
```

## sandbox mount

Open the sandbox session's TOS mount directory in TosBrowser. The tool must have a TOS mount, and the local machine must have an AgentKit login profile.

| Flag / Argument | Description | Default |
| --- | --- | --- |
| `-s, --session-id <id>, --sid <id>` | User session ID to mount; required. | Config `session-id` |
| `--oauth-url <url>` | OAuth profile URL; omit to use the active login profile. | Active profile |
| `--tool-id <id>` | Sandbox tool ID. | Config `tool-id` |
| `--tool-name <name>` | Sandbox tool name. | Config `tool-name` |
| `--tool-type <type>` | Sandbox tool type. | Config `tool-type` or `CodeEnv` |


## sandbox invoke

Invoke an agent in the sandbox through A2A. The command defaults to `SkillEnv`, creates or reuses a sandbox session, sends a prompt, waits for task completion, and prints JSON.

| Flag / Argument | Description | Default |
| --- | --- | --- |
| `[asyncMode]` | With `--async`, pass `true` or `false` to override async mode. | — |
| `-s, --session-id <id>, --sid <id>` | User session ID. | Config `session-id` or generated |
| `--prompt <prompt>` | Prompt to send to the sandbox A2A agent. | — |
| `--tool-id <id>` | Sandbox tool ID. | Config `tool-id` |
| `--tool-name <name>` | Sandbox tool name. | Config `tool-name` |
| `--tool-type <type>` | Sandbox tool type. | `SkillEnv` |
| `--async` | Return immediately after creating the A2A task. | `false` |
| `--task-id <id>` | Poll an existing A2A task. | — |
| `--ttl <seconds>` | Sandbox session TTL in seconds. | Config `ttl` or `28800` |
| `--model-name <name>` | Injected as `MODEL_AGENT_NAME`. | Config `model-name` or environment/sandbox config |
| `--model-provider <provider>` | Injected as `MODEL_AGENT_PROVIDER`. | Config `model-provider` or environment/sandbox config |
| `--model-base-url <url>` | Injected as `MODEL_AGENT_API_BASE`. | Config `model-base-url` or environment/sandbox config |
| `--model-api-key <key>` | Injected as `MODEL_AGENT_API_KEY`. | Config `model-api-key` or environment/sandbox config |
| `--timeout <seconds>` | Maximum wait time. | `1200` |
| `--interval <seconds>` | Polling interval. | `2` |
| `--history-length <count>` | A2A task history length to request. | `20` |
| `--a2a-path <path>` | A2A JSON-RPC path on the sandbox endpoint. | `/a2a` |

```bash
agentkit sandbox invoke \
  --tool-name assistant-skill \
  --session-id ask \
  --prompt "Summarize the project status"
```

Submit asynchronously and poll later:

```bash
agentkit sandbox invoke --tool-id tool-123456 --prompt "Start analysis" --async
agentkit sandbox invoke --tool-id tool-123456 --task-id task-123 --session-id ask
```

## sandbox run

Read `agentkit-sandbox-run.yaml`, convert entries into `agentkit sandbox exec` commands, and run them in the local terminal.

<Note>
When running one entry outside macOS, the CLI executes the command in the current process. Opening multiple terminal panes is currently supported in macOS Terminal and requires `tmux` on the local machine.
</Note>

| Flag / Argument | Description | Default |
| --- | --- | --- |
| `-f, --config <path>` | YAML file containing sandbox exec entries. | `agentkit-sandbox-run.yaml` |
| `--terminal <count>` | Number of exec entries to open or run. | `1` |
| `--dry-run` | Print the `agentkit sandbox exec` commands without running them. | `false` |

`agentkit-sandbox-run.yaml` may be a list or may contain an `exec`, `execs`, `tabs`, or `commands` field. Each entry supports `session_id`, `sid`, `tool_id`, `tool_type`, `command`, `mode`, `shell_id`, `git_config`, `model_name`, `model_api_key`, `model_provider`, `model_base_url`, `copy` / `copies`, `cwd` / `workdir`, `args` / `argv`, and display-only `name` / `title`.

```yaml agentkit-sandbox-run.yaml
execs:
  - name: tests
    session_id: dev
    tool_id: tool-123456
    copy:
      - ["./app", "sandbox:app"]
    command: "cd /home/gem/app && npm test"
  - name: codex
    session_id: dev
    tool_id: tool-123456
    mode: tmux
    command: "codex"
```

```bash
agentkit sandbox run --terminal 2
agentkit sandbox run --dry-run
```

## sandbox codex-login

Inject local Codex or Claude login credentials into a sandbox session. `codex-login` and `model-login` accept the same flags; `codex-login` defaults to Codex login and configures the `codex_login` model provider for `CodeEnv` sessions.

<Warning>
This command reads local subscription login credentials and writes OAuth login information into a remote sandbox session. Use it only with a trusted sandbox and a dedicated session, do not share that session, and re-inject after the session is recreated.
</Warning>

| Flag / Argument | Description | Default |
| --- | --- | --- |
| `-s, --session-id <id>, --sid <id>` | User session ID to inject into. | Config `session-id` or generated |
| `-p, --provider <provider>` | Subscription to inject: `codex` or `claude`. | `codex` |
| `--auth-file <path>` | Specific local credential file. | Provider default credential path |
| `--codex-home <path>` | Local Codex home. | `$CODEX_HOME` or `~/.codex` |
| `--login` | Run `codex login` when the local Codex credential is missing. | `true` |
| `--no-login` | Do not run `codex login` when the local Codex credential is missing. | `false` |
| `--tool-id <id>` | Sandbox tool ID. | Config `tool-id` |
| `--tool-name <name>` | Sandbox tool name. | Config `tool-name` |
| `--tool-type <type>` | Sandbox tool type. | `CodeEnv` |
| `--dry-run` | Print the redacted injection command without creating a session. | `false` |

```bash
agentkit sandbox codex-login --session-id dev --tool-name dev-code
agentkit sandbox codex-login --provider claude --session-id dev
```
