The `tree` command prints the CLI's full command tree, optionally expanding each command's arguments and options, or emitting machine-readable JSON.

## tree

Print the full command tree.

| Flag / Argument | Description | Default |
| --- | --- | --- |
| `--json` | Output the tree as JSON | `false` |
| `-a, --all` | Also show each command's arguments and options | `false` |

```bash lines
agentkit tree --all
```

The tree describes the locally installed version and requires no cloud account or project configuration. For an unrecognized option, check `agentkit --version` and the target command's `--help`

Save a command inventory for scripts:

```bash lines
agentkit tree --all --json > command-tree.json
```

The file contains command names, aliases, arguments, options, and subcommands. It describes CLI structure rather than cloud resources
